# Development log — October 2026

## 2026-10-28 — The platform

**Done:**
- The repository, from ai-robot's `protocol/cloud` and `protocol/setup` with their history: 25 commits, and the same files, now in `protocols/`. Links that pointed into ai-robot now point to it on GitHub, and the specifications name `ai-cloud` and `ai-app`.
- ai-robot's conventions, for a repository that holds protocols and decisions: `AGENTS.md`, `CLAUDE.md`, `CONTRIBUTING.md`, and the `adr`, `devlog`, `protocol-change` and `review` checklists.

**Decisions:**
- [ADR-0001](../decisions/0001-repositories.md), accepted: the repositories are a family, `ai-<what it is>`, and this one holds what they share; the protocols speak of devices.
- [ADR-0002](../decisions/0002-languages.md), accepted: Vietnamese first, any language added as data.

**Problems / unfinished:**
- The repository is private for now. ai-robot, which is public, can pin it only once it is public, so ai-robot keeps its own copy of the two protocols, unchanged, until then.
- No CI yet to check the schemas and the examples; ai-robot's tests still do.
- The specifications still say "robot".

**Next:**
- The repository public, then ai-robot pins it at `platform/` in place of its copy.
- A CI that validates every schema and example.
- Cloud link 3.0 and set-up 2.0, for devices (ADR-0001, decision 5).
- The catalogs' format (ADR-0002).

## 2026-10-28 — Reviewed for growth

**Done:**
- The owner asked for the foundations to be reviewed: what if the project grows a lot? Three things would be costly to change once devices ship, so they are proposed now:
  - how long each protocol version lives, and an update path that never breaks;
  - one way to write identifiers, time, errors and APIs;
  - homes as the unit of ownership, rather than accounts.
- CI, in its own pull request: every schema, every example, and a new minor version against the tag before it.
- The specifications now say that ai-robot ADR-0012, ADR-0014 and ADR-0015 are decided.

**Decisions:** [ADR-0003](../decisions/0003-compatibility.md), [ADR-0004](../decisions/0004-conventions.md) and [ADR-0005](../decisions/0005-homes.md), proposed.

**Next:** Cloud link 3.0 and set-up 2.0, for devices and homes; the update channel's format; the app's API.
