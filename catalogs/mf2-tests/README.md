# Unicode MessageFormat's test suite

A copy of the test suite that Unicode's MessageFormat working group publishes, for each component's MF2 library to run ([catalogs](../README.md#the-working-groups-tests)).

- **From** [unicode-org/message-format-wg](https://github.com/unicode-org/message-format-wg), its `test/tests/` and `test/schemas/` folders, at commit [`5c4ddb2`](https://github.com/unicode-org/message-format-wg/tree/5c4ddb27e726fd7881c1787a632efba83ab0d850/test) (2026-08-31).
- **Licence:** Unicode License v3. [`LICENSE`](LICENSE) is the repository's, as published: its first part covers the specification's text, which is not copied here, and the rest covers these tests.
- **To update it,** copy the same folders from a newer commit, record the commit here, and run each component's runner.
